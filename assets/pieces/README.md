# cburnett piece set

The twelve `*.png` files in this directory are rasterised versions of the
**cburnett** chess piece set.

- **Author:** Colin M. L. Burnett
- **Licence:** Creative Commons Attribution-ShareAlike 3.0 Unported
  (CC BY-SA 3.0) — <https://creativecommons.org/licenses/by-sa/3.0/>
- **Source:** <https://github.com/lichess-org/lila/tree/master/public/piece/cburnett>
  (files `wK.svg` … `bP.svg`)
- **Conversion:** `rsvg-convert -w 160 -h 160` to transparent PNG.

The SVG originals are kept alongside the PNGs for reference. If the piece set is
redistributed, this attribution must be preserved and derivative artwork must
remain under CC BY-SA 3.0.
