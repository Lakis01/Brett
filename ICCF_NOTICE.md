# ICCF correspondence database notice

Brett can use an optional ICCF correspondence database as a local, read-only
reference. Brett does not bundle, redistribute, or re-sell that database.

> **The ICCF database is provided for personal use only and may not be sold or
> re-sold to any third party.**

Obtain the database from ICCF, or compile it from ICCF server games under
ICCF's terms, and comply with ICCF's terms. The database is opened read-only;
Brett writes only derived position indexes under its cache directory and never
writes beside the source files.

This notice applies to the ICCF database and to any copy or derived data made
from it. It does not change the MIT licence of Brett's source code.
