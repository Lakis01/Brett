## SCID format reference

The native SCID reader in `src/scid.rs` is an independent implementation
written from the published SCID on-disk format. The GPL SCID source tree and
documentation were used as a format reference only.

- **SCID project:** <https://scid.sourceforge.net/>
- **Relationship:** no SCID source code is linked, copied, or distributed in
  Brett. Brett does not invoke `scidpgn` or any other SCID executable at
  runtime.
- **Test fixture:** `fixtures/scid/opera.*` was generated from the
  public-domain Opera Game in `fixtures/opera.pgn` using the `pgnscid` build
  tool. The generated database contains only that public-domain game and
  Brett-authored annotation markers. The SCID tools themselves are not
  redistributed.

The SCID trademark and project names belong to their respective owners. This
notice does not imply endorsement by the SCID project.

## Scid player photos (optional, not distributed)

Brett can display player portraits from an optional local photo pack. **No
photo data is included in this repository or in Brett's MIT-licensed source.**
The pack is derived from the Scid project's `Player_photos.zip`:

- **Upstream archive:** `scid/PlayerData/Player_photos.zip`, containing
  `Players.spf` — <https://sourceforge.net/projects/scid/files/Player%20Data/>
- **Derived format:** `photos.bin` (`BPF1`), generated by
  [`scripts/convert_spf.py`](scripts/convert_spf.py); portraits are re-encoded
  as WebP.
- **Relationship:** the photo data is not Brett-authored and is not covered by
  the MIT licence. Brett only reads a user-supplied pack at runtime.

**Redistribution warning.** The photo archive has no explicit redistribution
licence. Scid's `COPYING` file identifies database files as copyright Pascal
Georges and asks users to contact the respective authors before reusing those
files. Do not commit `assets/photos.bin`, bundle it in a release or installer,
or otherwise redistribute the photos without written permission from the rights
holders. See [`docs/PHOTOS.md`](docs/PHOTOS.md) for the full provenance,
build instructions, and local-only setup.

## Classic ChessBase CBH format reference

The native classic CBH reader in `src/cbh/` was written from independent
format references. No ChessBase installation, Wine runtime, or converter
executable is used.

- **cbvault** by Itshak (MIT): <https://github.com/itshak/cbvault>. Used as the
  independent validation oracle and as the source of the four move-encoding
  translation tables. Its documentation attributes parts of its format work
  to `asdfjkl/cbh2pgn` (MIT) and to `oschess-cb-bridge`.
- **cbvault-format** 0.1.4 (MIT): <https://crates.io/crates/cbvault-format>.
  A direct dependency used to read `.cbv`/`.cbz` containers. Its
  classic-format reader is a port of `cbformat` in `oschess-cb-bridge` at
  commit `ca9e8f8e`, which is MIT-licensed ("Copyright (c) 2026 the
  oschess-cb-bridge contributors"); the ported files retain the upstream
  notice. Brett links this crate as a normal Rust dependency.
- **cbh2pgn** by asdfjkl (MIT): <https://github.com/asdfjkl/cbh2pgn>. Used as
  an additional public format reference and cross-check.
- **oschess-cb-bridge** by asavis: <https://github.com/asavis/oschess-cb-bridge>.
  Its published format notes were consulted as format facts. The source of the

The source repository itself is distributed under the licences of its parts.

This is a known licensing limitation, not an intentional choice to ship a
permissive binary. Replacing these two crates with permissively licensed
